## NEW KEYWORD #9: AGENT

### Why Add a 9th Keyword?
After 5 years of stability (2026-2031), we are confident in the 8-keyword foundation.
The 9th keyword addresses the largest remaining failure mode: **AI agents making unaudited decisions**.

### Syntax

```ataj
# Define an AI Agent
AGENT FraudDetector with GOAL "Block fraud >99.9%"
  MODEL openai GPT-4 PIN 2.1.0
  SANDBOXED
  COST_CAP $100/day

# Trigger agent on events
ON payment.attempt DO AGENT FraudDetector

# Agents are just DOs under the hood
# AGENT expands to idempotent + circuit + audit + approval automatically
```

### Agent Safety Guarantees
1. Every AGENT action = `DO` with `idempotent` + `circuit` + `audit`
2. Cost-Guard applies to LLM calls (prevents $2M bill from rogue AI)
3. Human approval required for any action >$1000
4. All outputs validated against schema before execution
5. Rollback on any error (self-heal)

### Example: Full Pipeline

```ataj
APP Fintech multi-cloud aws gcp

AGENT FraudDetector with GOAL "Block fraud >99.9%"
 MODEL openai GPT-4 PIN 2.1.0
 SANDBOXED
 COST_CAP $100/day

USE stripe PIN 1.2.3
USE openai PIN 2.1.0

HAVE Transaction with id uuid amount decimal status enum
HAVE FraudReview with id uuid transaction_id uuid verdict enum confidence decimal

DO ProcessPayment and idempotent circuit approval from 2
 Call stripe.charge amount = Transaction.amount idempotency_key = Transaction.id
DO Emit transaction.processed

ON payment.attempt DO AGENT FraudDetector
 IF FraudDetector.verdict = "FRAUD"
 DO Block and approval from FraudTeam
 Call stripe.refund amount = Transaction.amount
 DO Audit and immutable
ELSE
 DO Approve and idempotent
 Call stripe.charge amount = Transaction.amount idempotency_key = Transaction.id
 DO Audit and immutable

WHEN 1st of month DO FraudReport and bulk
 FOR each Transaction DO Export to S3 WORM
```
