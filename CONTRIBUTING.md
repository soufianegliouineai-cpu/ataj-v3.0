# Contributing to ATAJ v3.0

## RULES - FROZEN FOR 5 YEARS
1. NO 9th keyword will be added
2. Every PR must pass 80/80 stress tests
3. Every DO must be idempotent by default
4. No new dependencies. Binary must stay <20MB

## Process
1. Fork
2. Add test to compiler/src/tests.rs
3. make test
4. Open PR

Violations = PR rejected.
